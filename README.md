Overview

This project analyzes consumer shopping behavior for a retail company to identify trends, understand customer preferences, and improve business decisions. The goal is to leverage data to enhance customer engagement, optimize marketing strategies, and increase overall sales performance.

---

Dataset

The dataset includes information on:

* Customer demographics (age, gender, etc.)
* Purchase behavior and frequency
* Product categories
* Discounts and reviews
* Sales channels (online vs. offline)
* Payment methods

---

Tools & Technologies

* Python (Jupyter Notebook) – Data cleaning and preprocessing
* MySQL Workbench – Data modeling and analysis using SQL
* Power BI – Data visualization and dashboard creation

---

Steps Performed

1. Data Preparation (Python)

* Handled missing values
* Cleaned and transformed data
* Created new features for analysis

2. Data Analysis (SQL)

* Built structured tables
* Segmented customers (New, Returning, Loyal)
* Analyzed purchase patterns and revenue trends
* Evaluated impact of discounts and reviews

3. Data Visualization (Power BI)

* Designed interactive dashboard
* Visualized sales trends and customer behavior
* Created KPIs for business insights

---

Dashboard Highlights

* Sales trends across product categories
* Customer segmentation analysis
* Online vs. offline purchase comparison
* Revenue contribution by demographics
* Impact of discounts and reviews

---

Key Results

* Repeat customers contribute significantly to revenue
* Discounts influence purchase decisions
* Customer behavior varies across demographics
* Seasonal trends affect product demand

---

How to Run

1. Clone the repository
2. Open Jupyter Notebook to run Python scripts
3. Import cleaned data into MySQL and run SQL queries
4. Open Power BI file to view dashboard

---

Conclusion

This project demonstrates how data analytics can be used to understand customer behavior and support data-driven decision-making in retail businesses.
